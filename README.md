# 🏡 Dự án Dự đoán Giá Nhà (House Price Prediction) - Nhóm 09

## 📌 Giới thiệu chung

Dự án này sử dụng các kỹ thuật Học máy (Machine Learning) để xây dựng mô hình dự đoán giá nhà dựa trên tập dữ liệu từ Kaggle.
Mục tiêu là so sánh và đánh giá hiệu suất dự đoán của các thuật toán khác nhau nhằm tìm ra mô hình tối ưu nhất.

## 💻 Công nghệ và Thư viện sử dụng

- **Ngôn ngữ:** Python
- **Thư viện nền tảng:** scikit-learn, Pandas, NumPy
- **Trực quan hóa dữ liệu:** Matplotlib, Seaborn
- **Môi trường phát triển:** Jupyter Notebook, Visual Studio Code
- **Quản lý mã nguồn:** GitHub

## 📊 Các mô hình triển khai

1. Hồi quy tuyến tính (Linear Regression)
2. Rừng ngẫu nhiên (Random Forest)

## 📁 Cấu trúc thư mục

- `data/`: Chứa dữ liệu đầu vào gốc (`train.csv`, `zone_info.json`).
- `Nhom09_DT24.ipynb`: Mã nguồn tiền xử lý dữ liệu, huấn luyện và đánh giá mô hình.
- `app.py`: Giao diện ứng dụng dự đoán (Deploy).
- `requirements.txt`: Danh sách các thư viện cần thiết.
